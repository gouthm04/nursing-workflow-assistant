# Nursing Workflow and Shift Handover Assistant

A mobile-based nursing workflow and shift handover assistant developed as an MCA mini-project.

## Technology Stack

- React Native
- Expo
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Gemini API

## Project Structure

- `mobile/` - React Native mobile application
- `backend/` - Node.js/Express backend
- `database/` - PostgreSQL database schema and seed data
- `docs/` - Project documentation and diagrams
